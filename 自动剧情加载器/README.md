## 使用方法及配置

1. 将任务脚本解压至 `process/` 目录
2. 将脚本添加至调度器
3. 右键点击脚本以修改 JS 自定义配置
4. 在设置中选择“刷新剧情列表”
5. 工具将扫描所有可用剧情脚本
6. 从更新后的列表中选择要执行的剧情
7. （可选）在脚本自定义配置中勾选「启用消息通知」，当脚本暂停、完成或报错时将通过 BetterGI 通知推送提醒
8. （可选）填写「暂停前按键操作(实验性功能)」—— 见下方说明

### 暂停相关配置

| 配置项                | 说明                                 |
| ------------------ | ---------------------------------- |
| **暂停键字符**          | 脚本暂停后，按此键继续执行（例如 `F10` 就直接填 `F10`） |
| **暂停前按键操作(实验性功能)** | 见下                                 |

**「暂停前按键操作」是什么**

当脚本因**非你主动操作**的原因暂停时（参数重载超出最大次数、注入脚本失败、
或剧情里写了 `暂停` 指令），脚本会在暂停**之前**先替你按一下这里填的键。
典型用途是**把游戏内时间暂停住**，避免脚本停住而游戏还在推进。

- **不填** → 不执行任何操作（保持原有行为）
- **填键名** → 例如填 `ESCAPE`，暂停前会按一下 Esc 打开菜单（游戏内时间暂停）

> 这是**实验性功能**：键名写错只会记一条警告，不影响正常的暂停流程。

**暂停通知格式**

勾选「启用消息通知」后，暂停通知会带上上下文，便于直接定位：

```
当前运行：捕风的异乡人9503，第78行 键鼠脚本 风起地神像精准2.0.json 3 主界面 true，超出最大循环次数，脚本已暂停，请手动操作游戏
```

依次是：**当前剧情名** → **第几行 + DSL 原文** → **实际暂停原因** → 操作提示。

## 全新框架开发指南

### 用法速览

- **放置位置**：仍使用原来的 `process/.../.../process.json`
- **文件内容**：可以直接写多行文本（无需 JSON）。冒号可用中文或英文
- **元数据（可选）**：开头写
  - `作者：xxx`
  - `描述：xxx`
- **任务块头**：以“任务描述字符串：”起一块，例如 `与纳西达对话：`
  - 匹配规则：OCR 获得的任务描述将做清洗（去特殊字符、大小写不敏感），用相似度≥0.90 的最佳匹配来选择块。相同描述的多个块按出现顺序执行（会记执行计数，下次匹配到会执行下一块）
  - 默认块（未匹配/超时13秒时执行）：块头可写 `默认：`、`无任务描述字符串：`、`default：`、`超时：` 等之一
- **指令行**：指令名与参数之间至少一个空格；`#` 与 `//` 为注释
  - `地图追踪 相对路径.json`
  - `键鼠脚本 相对路径.json`
  - **`地图追踪` / `键鼠脚本` 的参数重载（循环执行）** —— 支持 3 种写法：
    - 格式 1：`地图追踪 路径.json` —— 执行一次（最常用，与旧脚本完全兼容）
    - 格式 2：`地图追踪 路径.json 3 主界面 true` —— 最多 3 次，每轮后判断是否在主界面
    - 格式 3：`地图追踪 路径.json 3 图片.png true false` —— 最多 3 次，每轮后做模板匹配
    - 参数说明：
      - **次数**：`0-99`。`0` = 跳过此条（执行 0 次，不暂停）；`1` = 执行一次
      - **主界面**：字面量，必须原样写「主界面」。在 → 继续循环；不在 → 跳出
      - **图片路径**：相对 `process.json` 所在目录，模板匹配阈值 0.8
      - **布尔1**（仅格式 3）：`true` = 匹配到就继续循环；`false` = 没匹配到就继续循环
      - **布尔2**：跑满最大次数时 `true` = 暂停等待手动处理；`false` = 忽视并继续下一行
    - 示例：`地图追踪 路径1.json 3 paimon.png false false`
      = 最多跑 3 次，每轮后模板匹配；没匹配到就跳出；跑满则忽视继续下一行
  - `对话 NPC名`（简单格式下会自动开启 AutoSkip，交互→对话后等待回主界面）
  - `交互 目标名`（Alt+点击，不等待对话）
  - `等待返回主界面 超时秒数`（默认 600 秒）
  - `追踪图标 图标类型`（Bigmap/Question/默认Task）
  - `按键 键值`（例如 F，在只有一个选项的时候可以用来充当交互，最好写两个以防万一）
  - `等待 毫秒`（默认5000毫秒）
  - `任务完成`（立即退出整个流程）
  - `暂停 提示`（脚本会自己暂停自己，交由用户处理无法处理的事，提示非必填，在日志窗口输出）
  - `战斗`（在原地开启一次战斗，直接写进地图追踪文件里也可）
  - `自动拾取 开启/关闭` (开启关闭自动拾取,默认开启)
  - `切换 角色名` 切换单个角色（1号位）切换 枫原万叶
  - `切换 角色名1 角色名2` 切换多个角色（1、2号位）切换 枫原万叶 纳西妲
  - `切换 原来队伍` 切换回原来队伍
  - `提示 提示内容`  可以在脚本任意位置发一个提示
  - `调时间` 启动调时间键鼠脚本
  - `追踪委托 NPC名` 自动追踪并导航到委托目标 NPC（默认追踪 Bigmap 图标）
  - `点击 x,y` 点击屏幕坐标（支持中英文逗号），例如 `点击 960,540` 或 `点击 960，540`
  - `切换队伍 队伍类型 是否返回神像` 按队伍类型切换队伍，队伍类型可选 `战斗` 或 `元素采集`，是否返回神像填 `是` 或 `否`，例如 `切换队伍 战斗 否`、`切换队伍 元素采集 是`
  - `图像匹配 图像路径` 在任务文件夹下查找图像进行模板匹配并点击，例如 `图像匹配 1.jpg` 会查找 `process/当前任务/1.jpg`
  - `切换角色体型 角色体型` 识别当前队伍角色并切换到指定体型的角色（按下对应键位1/2/3/4），体型可选 `成男`、`成女`、`少男`、`少女`、`萝莉`，优先切换下标最前的角色，例如 `切换角色体型 成女`
  - `点击文字 x,y,w,h,文字` 在指定区域OCR识别文字并点击匹配项（支持中英文逗号）w 和 h是宽度和高度增量，从左上角 (x, y) 向右下延伸的矩形区域，例如 `点击文字 100,200,300,50,确认`表示识别从屏幕坐标 (100, 200) 开始、宽 300、高 50 的矩形区域内的文字。
  - `返回主界面` 调用 `genshin.returnMainUi()` 返回主界面
  - `按键 点按 键值` 与 `按键 键值` 等价，例如 `按键 点按 F`
  - `按键 长按 键值` 长按单个按键，默认 5000 毫秒，例如 `按键 长按 W`
  - `按键 长按 键值1,键值2 毫秒` 同步长按多个按键，可指定时长，例如 `按键 长按 Shift,W 4000`
  - `按键 按下 键值` 按下按键不松开，支持多键，例如 `按键 按下 Shift,W`
  - `按键 松开 键值` 释放已按下的按键，支持多键，例如 `按键 松开 Shift,W`
- **兼容旧格式**：
  - `F 纳西达` 等价 `对话 纳西达`
  - `xxx.json` 等价 `地图追踪 xxx.json`

### 示例新结构（可断点续跑，带重试机制）

```
作者：星野
描述：示例流程

与特纳对话：
父亲能做的事-晨曦酒庄-1.json
F 特纳

找吉丽安娜配药:
父亲能做的事-晨曦酒庄-2.json
F 吉丽安娜

向特纳回报:
父亲能做的事-晨曦酒庄-3.json
F 特纳
任务完成

默认：
父亲能做的事-晨曦酒庄-1.json
自动拾取 开启
F 特纳
```

- 重复任务描述的块按上下顺序依次执行；第一次匹配到执行第一个，再次匹配到执行第二个，以此类推
- 未检测到任务描述时，会每秒检测一次，13 秒仍未匹配则执行默认块（若存在）

### 其它说明

- “对话”指令会尝试优先 Alt+点击包含 NPC 名称的文本区域触发交互，然后执行 AutoSkip 自动跳过剧情并等待返回主界面
- “交互”指令只做 Alt+点击，不等待对话
- “追踪图标”支持 Bigmap/Question/默认 Task 图标
- 原 JSON 数组流程保持兼容
